Description

With access to the camera feed inside a target building established prior by a cyber element or through a hardline connection, IRIS fuses data from the adversary’s own security system to construct a live interior picture for the assault element.

The picture is comprised of a full floorplan with real-time person identification and tracking throughout all visible rooms. The IRIS ruggedized unit is designed to attach to the exterior of an operator’s assault pack, allowing all inference to be conducted on-site with no reach-back, network connectivity or traceable RF signature.
