# Security

This repository holds the public website of Initium Technologies (initiumtechnologies.com). It is a static site:
no server code, no accounts, no user data and no third-party scripts.

## Reporting a problem
Email **admin@initiumtechnologies.com** with "Website security" in the subject. Include the page address, what you
saw and how to reproduce it. We aim to acknowledge reports within two business days.

Please do not open a public issue for a security report.

## Scope
- In scope: everything served under initiumtechnologies.com, the contents of this repository and its build pipeline.
- Out of scope: partner.initiumtechnologies.com (a separate system; report to the same address) and third-party
  services the site links to.
